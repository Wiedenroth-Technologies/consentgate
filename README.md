# ConsentGate

WordPress plugin for GDPR / DSGVO cookie consent. It provides a cookie banner, script blocking, Google Consent Mode v2, a site service scan, and a consent log.

This repository is the source for the plugin listed on WordPress.org:

https://wordpress.org/plugins/wiedenroth-technologies-consentgate/

Product page: https://wiedenroth.tech/software/consentgate

## Requirements

- WordPress 6.4 or later
- PHP 8.1 or later
